# meldenv

Meld list/env set operations for shell-friendly data wrangling.

**Site:** https://theworker02.github.io/meldenv/

## Install / run

```bash
git clone https://github.com/theworker02/meldenv.git
cd meldenv
node src/cli.js
node --test
```
